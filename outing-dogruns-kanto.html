関東のドッグラン10選。

室内・屋根付き・天然芝・水遊び・無料。今日はどこで遊ぶ？

情報確認 2026.09.19 / すいとおん。

広い芝生で走りたい日も、雨を避けて遊びたい日も。関東の10施設を、遊べる環境と初回の準備で選べるようにまとめました。順位ではなく、目的別の候補です。訪問した寄七つ星・豊洲ぐるり以外は、公式情報から選んだ未訪問の施設です。

今日の気分で選ぶなら。

室内ならWANCOTT・DOG ISLAND瀬谷・DOG RUN TOKYO・ペットステーションWAN。屋根付きも選択肢に入れるなら、わんダフルネイチャーヴィレッジ・グランデ常陸。天然芝や水遊びならドギーズアイランド、訪問して広さがうれしかった寄七つ星も。無料で探すなら豊洲ぐるり・代々木公園です。

屋根付きは雨風を完全に避けられる室内とは別。無料のランでも事前登録や駐車料金を確認しておきましょう。

01 / 神奈川・足柄上郡松田町

寄七つ星ドッグラン

すいとおん家の訪問メモ：初めて行きましたが、広くてたくさん走り回れるのがとても良かったです！体格でエリアが分かれていて、プールもありました。

料金の目安
地域の施設案内掲載：大人330円、小人220円、犬1頭440円、駐車1区画500円。大人1人＋犬2頭＋駐車1区画の計算例は1,710円。追加施設の料金・最新料金は来園前に確認してください。
登録・予約
初回の登録方法・予約要否は今回の公式確認範囲では未確認です。施設へ事前に確認してください（0465-89-3113）。

02 / 東京・江東区豊洲

豊洲ぐるりドッグラン

すいとおん家も利用して良かったドッグラン。利用無料ですが、事前の会員登録が必要です。私の場合、登録には２日かかりました。

料金の目安
ドッグラン利用無料。隣接する豊洲ぐるり公園駐車場は400円／時間（公式案内掲載）。駐車料金は別途必要です。
登録・予約
来場前の会員登録が必要。公式ページにはWEB申請後に管理事務所で会員証を受け取る方法と、試験導入中のWan!Passによるオンライン登録の案内があります。選んだ方法の最新手順を確認してください。

WANCOTT

雨の日にも走れる、屋内ドッグパーク。初回は会員登録を済ませてから。

登録・予約
WEB会員登録 → 来館時に原本確認。通常のドッグパークは予約不要。

04 / 東京・あきる野

わんダフルネイチャーヴィレッジ

屋外ランに加え、屋根付きエリアも。完全な室内とは分けて選びたい場所。

通常入園料で利用。貸切ランなど一部施設は別途予約・料金が必要。初回の手続き詳細は要確認。

05 / 東京・渋谷

代々木公園ドッグラン

06 / 神奈川・横浜市瀬谷区

DOG ISLAND 瀬谷店

早朝や夕方にも選びやすい、空調付きの完全屋内ラン。無人営業なので、登録と予約は出発前に。

料金の目安
1頭50分900円。駐車場は無料・予約制（6台）。貸切料金は公式で確認。
登録・予約
WEB登録の承認後、犬のサイズに合う時間枠を予約・カード決済。駐車場付きの枠を選んでください。

07 / 東京・渋谷区千駄ヶ谷

DOG RUN TOKYO

体重別の時間枠を選んで遊ぶ室内ラン。カフェを併設し、北参道駅から徒歩約5分。

料金の目安
飼い主1名＋犬1頭・50分：平日2,980円、土日祝3,480円。犬1頭追加990円。飼い主1名につき合計3頭まで。
登録・予約
完全予約制・事前カード決済。日時予約とチケット購入が必要。追加の犬・付き添いは別途チケットを購入。

08 / 埼玉・三郷市

ペットステーションWAN

約20坪の室内ラン「WAN・WAN広場」。通常利用は小型・中型犬向け、大型犬は貸切で。

料金の目安
通常利用は犬1頭30分550円（税込表記）。貸切1時間3,300円（税込表記）。駐車場は近隣コインパーキング。
登録・予約
来店前に公式の貸切予定を確認。貸切の予約は遅くとも1週間前まで。通常利用の初回登録要否は店舗に確認（048-951-3114）。

小谷流の里 ドギーズアイランド（日帰り）

天然芝のランで思いきり走って、水遊びや散策も楽しみたい日に。体格・犬種に応じたエリアと全犬種エリアがあり、遊び方を選べます。

料金の目安
大人：平日1,000円／土日祝1,200円。犬：小型800／1,100円、中型1,000／1,300円、大型1,200／1,500円。2頭目以降は割引あり。日帰り駐車800円。税込。
登録・予約
受付で登録後に利用。貸切ランは事前予約が必要です。初回受付の所要時間は公表なし。
